# Tipografia — Turismo Aventura Santos

Carregada via `next/font/google` em `src/app/layout.tsx`:

| Papel | Família | Uso |
|-------|---------|-----|
| Display | **Bricolage Grotesque** (700–800) | Hero, H2, preços, statements |
